# Heimdall — менеджер паролей

Дипломный проект по специальности 10.05.01 «Компьютерная безопасность».

## Статус
- :hourglass: Анализ существующих решений
- :x: Выбор криптографических примитивов
- :x: Каркас приложения
- :x: Шифрование хранилища
- :x: Интеграция с ГОСТ-алгоритмами
- :x: Сборка под Astra Linux

## Структура
- `docs/` — документация (НИР, диплом, требования)
- `src/` — исходный код на C++/Qt
- `scripts/` — вспомогательные скрипты

## Сборка
Требуется Qt 5.15.19 и MinGW-w64 (MSYS2).
